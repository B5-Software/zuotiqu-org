# M5：录取数据与模拟志愿

## 状态（先说结论）

**真实的省级数据没有收录。** 这一轮完成的是管线、模型、算法、页面和测试。页面目前使用的是 `scripts/make-demo-gaokao.mjs` 生成的**虚构演示数据**（学校名以"示例"开头，分数线由固定种子生成），页面和文档里都有明显的提示。

计划里的 E1（3 个试点省份、真实数据、抽检准确率）**未完成**，需要逐省核对官方公开数据后才能做。

## 做了什么

- 数据模型与校验：`src/lib/gaokao/schema.ts`（zod）。
  - 一分一段表：`scoreRanks`，区分文理科（老高考）。
  - 院校：`schools`。
  - 专业组：`groups`，带选科要求（首选、必选、再选任一组）、批次、计划人数、最低分与最低位次、`sourceUrl`、`fetchedAt`。
  - 语义校验：院校引用、分数降序、累计人数单调、老高考不应有选科要求。
- 换算：`src/lib/gaokao/rank.ts`。分数换算位次时同分取最前位次；分数不在表中时取较低一档（偏保守）；超出表范围时标记为估算。
- 选科过滤：`src/lib/gaokao/requirements.ts`。不符合选科的专业组直接排除，不出现在结果里。
- 冲稳保：`src/lib/gaokao/match.ts`。
  - 比值 = 你的位次 ÷ 专业组最低位次。
  - 取最近 3 年比值的中位数分档：≤0.95 保，≤1.05 稳，≤1.25 冲，超出不列入。
  - 分数输入时，每一年都用该年的一分一段表换算位次。
  - 依据、数据年份不足、波动较大都会给出提示。
  - 不给录取概率百分比。
- 页面：
  - `/gaokao`：选省份、分数或位次、选科、批次；结果分冲稳保三列；每条有依据展开；模拟志愿表支持拖拽和按钮排序、复制文本、生成分享图。
  - `/gaokao/schools`：按省份、层次、地区、关键词筛选；展开看近几年各专业组的分数与位次。
- 免责声明在表单上方，结果里有"结果的不确定性"说明。

## 测试

- `tests/gaokao.test.ts`：一分一段换算边界（精确、同分、低于、高于、空表）、选科与科类过滤、冲稳保档位边界、只有一年数据、某年缺数据、分年份换算、输入校验。
- `tests/gaokao-data.test.ts`：对 `public/data/gaokao/` 下所有演示数据做 schema 与语义校验，并检查每条专业组都带来源与抓取时间。
