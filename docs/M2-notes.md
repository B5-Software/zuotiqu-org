# M2：超纲解法生成器

## 做了什么

- 10 个题型模板（`src/lib/overkill/templates.ts`）：一元一次方程、一加一、两点间最短距离、1 加到 n、三角形内角和、圆的面积、鸡兔同笼、求百分之几、最大公约数、勾股定理。
- 每个模板 3 种荒诞解法，解法步骤里的公式用 KaTeX 渲染。解法的推导是真实可读的（例如最大公约数的欧几里得算法步骤是按参数实际算出来的）。
- 标准答案由 mathjs 计算。mathjs 只注册了用到的因子函数（`create({...})`），没有全量引入。
- 评级：取三个解法里的最高降维指数，映射到 5 档文案。
- 分享：生成分享图。
- 默认纯前端、模板驱动，不依赖 LLM。

## 测试

- `tests/overkill.test.ts` 共 10 个用例：每个题型随机跑 1000 次，标准答案函数无异常；一元一次方程用解回代校验；最大公约数用独立计算校验；鸡兔同笼校验头数与腿数；三角形内角和校验 180°。

## 没做

- LLM 自由输入题目（计划里明确是 M2 之后再说）。

## 已知问题

- 每个模板只有 3 种解法，抽到的组合固定，只是顺序随机。
- 页面 JS 约 570KB（未压缩），主要是 KaTeX 和 mathjs，只在本页和快跑所在页面加载。
