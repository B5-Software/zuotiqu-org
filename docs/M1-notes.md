# M1：黑话 Wiki

## 做了什么

- 词条：`content/wiki/*.md` 共 15 条，frontmatter 由 Astro content collection + zod 校验（`src/content.config.ts`）。
- 页面：`/wiki`（搜索、随机、分类筛选、投稿）、`/wiki/<slug>`（词条页）、`/wiki/category/<分类>`。
- 搜索：MiniSearch，自定义 CJK 切词。索引侧保留整段、单字、双字；查询侧只用单字和双字并以 AND 组合。别名参与搜索。测试在 `tests/wiki-search.test.ts`。
- 投稿：页面上的"我要补充"跳转到 GitHub issue 模板 `.github/ISSUE_TEMPLATE/wiki-entry.yml`，标题会预填词条名。
- 投稿规范：`content/wiki/CONTRIBUTING.md`。

## 出处核实情况

- 有可靠来源的：优绩主义、内卷、小镇做题家、985 废物引进计划、洛必达（数学本义）、早八、班味等。
- 标为"待考证"的：超纲解法（定义是站内模块自身的设定）、草稿纸、错题本、刷题，以及做题区的首次出现、洛必达梗义的首次出现、满分作文模板这一术语。
- 已修正的表述：早八的日期是推断，已注明；班味的"十大流行语"是台湾媒体转述，已注明未核对原文；985 废物引进计划的成员数来自二手舆情报告，已注明；去掉了原稿里一个真实人名，学校名也改为泛称。
