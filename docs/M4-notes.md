# M4：做题区快跑

## 做了什么

- 逻辑与渲染分离：
  - `src/lib/run/world.ts`：纯模拟（固定步长 1/60 秒）、碰撞、刷新、难度、拾取物效果。
  - `src/lib/run/render.ts`：Canvas 2D 绘制。
  - `src/lib/run/ui.ts`：循环、输入、暂停、最高分、结算。
- 障碍：作业堆、早八闹钟、家长群通知（蹲下可过）、月考排名榜（高，需要起跳）。
- 收集物：满分卷（+30 卷度，得意姿态）、咖啡（短时起跳更高）、草稿纸（抵消一次碰撞）、洛必达（6 秒无敌并加速）。
- 难度：卷度越高，速度越快、刷新间隔越短，都有上限。
- 角色：头部使用原创头像 SVG，身体为几何图形。姿态由代码生成：跑、跳、蹲、摔倒、得意、被作业压住。
- 输入：空格 / ↑ / W 跳跃，↓ / S 蹲下；触屏点击上半屏跳跃、下半屏长按蹲下；P / Esc 暂停；失焦或切换标签页自动暂停。
- 音效：WebAudio 合成，默认关闭，开关保存在 localStorage。
- 最高分保存在 localStorage。没有排行榜（计划里明确暂不做）。

## 测试

- `tests/run-world.test.ts` 共 14 个用例：边缘接触不算碰撞、蹲下碰撞框变矮、跳跃最高点在合理范围、空中下压快落地、护盾抵消一次碰撞、无敌穿过障碍、满分卷奖励、难度单调、同一种子结果一致、自动驾驶能存活 8 秒以上、10 分钟模拟实体数量有界。
- 浏览器端冒烟：开始、跳跃、暂停、撞上障碍后出现结算。

## 没做 / 已知问题

- 角色姿态只是几何图形，没有经过美术打磨。
- 没有在真机上测过触屏手感，只在桌面 Edge 上用无头模式测了。
- 碰撞框做了内缩（左右各 4px，上下各 3px），减少误判，但没有做系统化的手感调参。
