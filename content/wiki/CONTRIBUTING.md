# 黑话 Wiki 编辑规范

本规范面向所有投稿者。词条用于客观记录做题区与学生黑话的含义、来源和用法，请在投稿前阅读。

## 基本原则

- **客观描述**：采用词典式写法，说明词义、来源和用法，不作价值评判。
- **不引战**：不针对个人、群体、地区、学校、性别、外貌或出身进行嘲笑或攻击。讽刺的对象应是评价体系、优绩主义和内卷文化。
- **不放真实个人信息**：正文、例句和来源中不得出现真实的姓名、学校、老师、同学，也不得出现账号、联系方式或照片。
- **不编造**：出处、年份、人物和引文必须有可查证的依据。网络上未经核实的段子不能当作事实写。
- **带贬义的词必须标明**：在 `note` 中写明其贬义色彩，以及语义流变的过程。

## 出处与来源

- 每条 `origin` 中的关键事实（时间、平台、人物或小组、首次出现）都应能在 `sources` 的链接中找到依据。
- `sources` 的每一项必须是完整的 `http(s)` URL。
- 没有可靠来源时，`origin` 写“待考证”，`sources` 写 `[]`。不要为了凑数而填写不相关的链接。

## frontmatter 字段

| 字段 | 说明 |
| --- | --- |
| `term` | 词条名称。 |
| `aliases` | 别名或相关称呼。没有则写 `[]`。 |
| `category` | 只能是 `梗`、`学习`、`考试`、`校园`、`网络` 之一。 |
| `definition` | 一句话释义。 |
| `origin` | 出处与时间线。没有可靠来源写“待考证”。 |
| `example` | 原创例句。不要抄袭真实评论或帖子，不要出现真实的人、学校、老师或同学。 |
| `related` | 相关词条名称，与对应词条的 `term` 保持一致。没有则写 `[]`。 |
| `sources` | 完整的 `http(s)` 链接列表。没有则写 `[]`。 |
| `note` | 可选。用于说明贬义、语义流变或争议。 |

## 正文

- 用 Markdown 写 2–4 段。
- 词典式地客观描述词义、来源和用法。
- 不重复复述歧视性或攻击性的刻板印象。

## 文件与命名

- 每个词条一个 `.md` 文件，文件名即词条的 slug，使用小写拼音或英文，单词之间用连字符连接。例如 `zuotiqu.md`。
- `CONTRIBUTING.md` 是本规范文件，不会被当作词条收录。
